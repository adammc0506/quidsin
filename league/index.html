A league table that keeps itself

Add the teams or players and choose the points for a win and a draw. Generate fixtures so everyone plays everyone once, or home and away. Enter results and the table updates for everyone following.

How it works

  1. Add the teams and set the points for a win and a draw.
  2. Generate the fixtures, or add results as they happen.
  3. Share the code so everyone can follow the table.

Questions

How is the league table ordered?

By points, then difference, then goals or frames scored, then name.

Can I change the points for a win?

Yes. Set the points for a win and a draw when you create the league.
