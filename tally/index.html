Tab & Tally › Tally

Keep score without the arguments

Tally is a shared scoreboard. The scorekeeper taps a name to add or take off points, and everyone else watches the leaderboard update on their own phone. Choose whether the highest or lowest score wins.

How it works

  1. Add the players and choose whether high or low wins.
  2. Tap a name to add points. Undo the last score if you slip.
  3. Share the code so everyone can watch.

Questions

Can others change the scores?

No. Only the scorekeeper link can change scores.

Does it work for golf or darts?

Yes. Choose lowest score wins for golf-style games.
