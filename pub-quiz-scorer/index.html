Tab & Tally

Pub quiz scorer with a live leaderboard

Adding up quiz scores on paper gets slow and error-prone around round five. This scorer keeps a running total for every team and shows everyone the leaderboard on their own phone.

Start a quiz

Setting up

  1. Add the teams. You can add more later if someone turns up late.
  2. Choose the number of rounds. You can add, rename or remove rounds at any time.
  3. Share the code or QR code so teams can watch the leaderboard.

Scoring a round

Pick the round, then type each team's score. Half points are fine, and there are quick buttons for +1 and −½. Totals and rankings update straight away for everyone watching.

Made a mistake? Type the new number over the old one, or clear it.

Tips for a smoother quiz night

  • Keep a bonus or tiebreaker round at the end and add it as an extra round.
  • Read out the leaderboard after each round, but hold back the last one for drama.
  • Let teams swap their answer sheets to mark each other's, then enter the totals yourself.
  • Share the code on the screen or on a poster so teams can follow along without asking.

Questions

Can teams see the scores?

Yes. Everyone with the code sees the leaderboard and a round-by-round grid. Only the quizmaster can change scores.

Can I use half points?

Yes, scores can be whole or half points.

How many teams and rounds?

Up to 40 teams and 30 rounds.

How long is the quiz kept?

It is deleted after 30 days, or 3 months if you choose.
